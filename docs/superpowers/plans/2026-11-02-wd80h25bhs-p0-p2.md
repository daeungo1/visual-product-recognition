## WD80H25BHS P0-P2 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build an exact-product, reviewed-reference, multi-target visual guide
for Samsung `WD80H25BHS` and validate it on the three supplied images.

**Architecture:** FastAPI loads a fail-closed reviewed product registry and
manual evidence. GPT-6.1 Terra proposes one target at a time, while the server
aggregates three proposals and performs one bounded adaptive-crop retry before
returning independent target results.

**Tech Stack:** Python 3.11, FastAPI, Pydantic, Pillow, a pinned Poppler CLI,
OpenAI Azure client, pytest, Ruff and Azure Container Apps.

**Spec:** `docs/superpowers/specs/2026-11-02-wd80h25bhs-p0-p2-design.md`

## Global Constraints

* Support only exact model `WD80H25BHS` in this vertical slice.
* Identify manuals by SHA-256 and applicability metadata, not local filename.
* Keep raw PDF and product images excluded from Git.
* Use strict Pydantic contracts with `extra="forbid"`.
* Return geometry only for `located` targets.
* Preserve independent status and partial success for every requested target.
* Perform at most one adaptive crop retry per target.
* Map crop coordinates back to root-image pixels in deterministic code.
* Keep current authentication and request-image non-persistence behavior.
* Defer SAM, GPU, video tracking and AR to P3 and later.

## Review Focus

* A manual with a misleading filename but matching reviewed hash must load.
* A manual with the right model string but the wrong hash must be rejected.
* Two requested targets must never collapse into one shared status or box.
* Crop retries must never leak crop-relative coordinates to the root response.
* A located target and an uncertain target must remain a partial success.
